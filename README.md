# persian-asr

Persian ASR baselines for THU-SPMI (Prof. Zhijian Ou): subword-based **S1** (Conformer-CTC from scratch)
and **S2** (Whistle-small encoder + new Persian BPE head), with phoneme-based **P0/P1** later. Built on
[CAT](https://github.com/thu-spmi/CAT) / [Whistle](https://arxiv.org/abs/2406.02166). Training runs on Google Colab.

- `src/persian_asr/`: library code (environment checks, cached installs, Whistle checkpoint handling, features, smoke tests)
- `tests/`: CPU tests (`pytest`)
- `notebooks/`: one Colab notebook per step, generated by `scripts/make_notebooks.py` (edit that, not the `.ipynb`)
- `scripts/build_kaldi_min.sh`: minimal static Kaldi for CAT's WFST decoding
- `scripts/run_notebook_locally.py`: runs a notebook on CPU with `google.colab` faked
- `third_party/cat_ext_stubs/`: import-only stubs for CAT's unused compiled extensions (see its README)
- `PROGRESS.md`: status, findings with CAT file:line references, next steps

Data, features, LMs and checkpoints live only on Google Drive under `MyDrive/persian_asr/`.

## Local development (CPU)

```bash
python3 -m venv .venv && . .venv/bin/activate
pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu
pip install -r requirements-dev.txt
# CAT (no CUDA extensions) + stubs:
git clone https://github.com/thu-spmi/CAT.git /path/CAT && git -C /path/CAT checkout 2340970f04
pip install third_party/cat_ext_stubs && pip install --no-deps -e /path/CAT
pip install "git+https://github.com/webdataset/webdataset.git@d7334016f44a03c4a385971aa835c4f460d3f30a" https://github.com/kpu/kenlm/archive/master.zip
pytest -q
python scripts/make_notebooks.py
```
